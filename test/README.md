# test/ — 動作検証用Markdownサンプル

note.com への貼り付けテストや、変換ロジック（Sprint 4-7）の検証に使うサンプルファイル。

## ファイル一覧

| ファイル | 用途 | サイズ感 |
|---------|------|---------|
| `sample-realistic.md` | 実利用に近い記事スタイルのサンプル。日常テスト・デモ用 | 約600字 |
| `sample-syntax-full.md` | 全Markdown構文の網羅テスト。Sprint 4-7の各構文変換確認用 | 約1,200字 |

## 使い方

### 現状（Sprint 2 時点）
ボタンクリックで「未実装」メッセージが出るだけ。textareaへの貼り付け動作と日本語表示の崩れがないかの確認に使えます。

### Sprint 3 以降
1. ファイル内容をすべてコピー（VS Codeなどで開いて Ctrl+A → Ctrl+C）
2. 拡張機能のポップアップを開く
3. textareaに貼り付け
4. 「プレビュー」ボタンで変換結果を確認（Sprint 3〜）
5. 「変換してコピー」ボタンでクリップボードへリッチコピー（Sprint 5〜）
6. note.com の執筆画面（https://note.com/notes/new）に貼り付けて装飾の反映を目視確認

## 確認すべき変換ルール（Sprint 4 仕様より）

- [ ] `#` 見出し → noteの h2 に変換される
- [ ] `##` `###` → そのまま
- [ ] `####` 以下 → 太字段落に変換される
- [ ] `**太字**` `*斜体*` `` `コード` `` → そのまま
- [ ] リスト（順序付き／なし） → そのまま
- [ ] `>` 引用 → noteの引用形式
- [ ] コードブロック → 等幅フォント
- [ ] `[link](url)` → そのまま
- [ ] `![alt](url)` 画像 → URL段落 + 「note側で再アップロード」注釈
