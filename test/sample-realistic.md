# AIライティングの効率を10倍にするツール選び

最近、ChatGPTやClaudeで記事を書く人が増えています。しかし、**生成したMarkdownをnoteに貼り付けると装飾が崩れる**という問題に直面した人も多いはず。

この記事では、私が実際に使っている解決策を紹介します。

## 結論：3つのツールを組み合わせる

具体的には以下の流れです。

1. **執筆**：ChatGPT または Claude（[anthropic.com](https://www.anthropic.com)）
2. **整形**：Markdown to note（このChrome拡張）
3. **公開**：noteの執筆画面に貼り付けるだけ

たったこれだけで、AIで書いた記事が *そのまま* noteで読める形になります。

## なぜMarkdownで書くのか

Markdownはシンプルな記法で構造化された文章を書けます。たとえば `# 見出し` と書くだけで見出しになり、`**太字**` で強調が入る。

> Markdownを覚えると、AIへの指示も書きやすくなる。
> 構造化された思考が身につくのが最大のメリットだ。

### 学習コストはほぼゼロ

覚えるのは10分程度です。最低限のルールは下記の3つだけ。

- 見出しは `#` の数で階層を表す
- 強調は `**太字**` と `*斜体*`
- リンクは `[表示テキスト](URL)`

### コードもそのまま書ける

```javascript
const greeting = "Hello, note!";
console.log(greeting);
```

技術系の記事もこれで書けてしまう。

## 画像はどうなる？

画像URLが含まれている場合、Markdown to noteは自動でURLを抽出して注釈を付けてくれます。

![サンプル画像](https://example.com/sample.jpg)

note側で画像を手動アップロードすればOK。

- AIで書いた記事をnoteに貼るのが一気に楽になる
- 完全無料、永久無料
- 通信ゼロで安心
