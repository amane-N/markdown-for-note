## 詳細説明

**最大 16,000 文字（推奨 800〜1,500 文字）**

```
Markdown for note は、ChatGPT・Claude・Notion・Obsidian など他のツールで書いた Markdown 記事を、ワンクリックで note.com の執筆画面に「装飾を保ったまま」貼り付けられる Chrome 拡張機能です。

▼ こんな悩みを解決します
・noteに転載するたびに、見出しや太字を手作業で付け直している
・Markdownのコピペがそのままただのテキストになってしまってがっかりした
・ChatGPT/Claudeが出力したMarkdownを、装飾付きで note に持って行きたい
・noteの執筆画面で「## 見出し」と書いても見出しにならず困っている

▼ 主な機能
・Markdown を貼り付けて「変換してコピー」ボタンを押すだけ
・見出し（h1〜h3）、太字、斜体、取り消し線、リンク、リスト、引用、コードブロック、インラインコードに対応
・note のエディタが受け付けるリッチテキスト（HTML）形式でクリップボードにコピー
・プレビュー機能で貼り付け前の見た目を確認可能（おおよその文字数も表示）
・画像 URL は自動検出して一覧表示。note の手動アップロード作業をスムーズに
・h1 → h2 自動変換、画像注釈の有無、自動プレビューなど細かい設定をカスタマイズ可能

▼ 動作の流れ（10秒）
1. ChatGPT や Claude で記事を Markdown で書く
2. このアイコンをクリックしてポップアップを開く
3. Markdown を貼り付けて「変換してコピー」を押す
4. note の執筆画面に Ctrl+V（macは Cmd+V）で貼り付け → 装飾そのまま完成

▼ プライバシー
・通信は一切行いません。すべてブラウザ内で完結します
・入力されたテキストや変換結果が外部サーバーに送信されることはありません
・収集・追跡は行いません。広告も入りません
・設定情報のみ chrome.storage.local（あなたの端末内）に保存されます

▼ こんな人におすすめ
・AIで下書きをしてからnoteに清書するライター
・Notion / Obsidian / VSCode で書く習慣のあるブロガー
・複数媒体（note・はてな・Zenn）に同じ記事を出すクロスポスト派
・「note の執筆画面でMarkdown記法が使えない」のにモヤモヤしている方

▼ 制限事項（正直に書きます）
・GitHub Flavored Markdown のテーブルは note のエディタが非対応のため、変換時に削除されます（警告で通知します）
・画像は note の仕様上、自動アップロードできません。URL一覧をワンクリックでコピーできるようにしてあるので、note の挿入機能で個別に追加してください
・既知の Markdown 拡張記法（脚注、定義リスト、Mermaid 図など）は未対応です

▼ 開発について
個人開発（Made by Amane.N）。バグ報告・機能要望はストアレビューでお気軽にどうぞ。

すべて完全無料・永久無料。あなたの執筆体験が少しでも軽くなりますように。

※ 本拡張機能は note 株式会社が提供するサービス「note」（note.com）で利用することを目的とした、第三者によるサードパーティツールです。note 株式会社とは無関係であり、同社による公式サポート対象ではありません。
```
