# ストア提出物 制作チェックリスト

> Claude Code では作れない画像系成果物のガイド。Canva / Figma / OS の標準ツールで制作。

## 1. アイコン（必須・3サイズ）

### 仕様
| ファイル名 | サイズ | 用途 |
|---|---|---|
| `icons/icon16.png` | 16×16 px | ツールバー右上の小アイコン |
| `icons/icon48.png` | 48×48 px | 拡張機能管理画面 |
| `icons/icon128.png` | 128×128 px | Chrome Web Store の一覧 |

### デザイン指針
- 背景色：note ブランドグリーン `#41C9B4`（角丸 22% 程度推奨）
- ロゴ：白の `M→n` または `Md→n` を中央配置
- シンプルで小さくても識別可能なものに
- フォント：太めのサンセリフ（Inter Bold / Noto Sans Bold など）
- 16px 用は文字を `M` 1文字だけにするなど最大限シンプルに

### Canva での制作手順
1. Canva で「カスタムサイズ」→ `128×128 px` を作成
2. 背景を `#41C9B4` に塗り、白文字で `M→n` を中央配置
3. PNG（透過ON）で書き出し → `icons/icon128.png` として保存
4. 同じデザインを 48×48、16×16 にもリサイズして書き出し
5. Chrome 拡張に再読み込みし、ツールバー・管理画面で見え方を確認

### 既存のプレースホルダーを置き換える
現在 `icons/` には開発用の最小プレースホルダー画像が入っているので上書き保存。

## 2. スクリーンショット（必須・5枚）

### 仕様
| 項目 | 値 |
|---|---|
| サイズ | 1280×800 または 640×400（推奨は 1280×800） |
| フォーマット | PNG または JPEG |
| 最低 1 枚、最大 5 枚 |
| 言語 | 日本語スクリーン推奨（プライマリ言語と一致） |

### 撮影プラン

**①メインビジュアル：「3秒で何ができるかわかる」スクショ**
- ポップアップ全体 + 矢印テキスト「Markdown を貼って → ボタン押すだけ」
- 上部に大きいタイトル「他のエディタやAIで書いたMarkdownを、ワンクリックでnoteへ」

**②Markdown 入力中**
- ポップアップを開いた状態で、ChatGPT/Claude 風の Markdown が入力されている画面
- 背景に少しだけ ChatGPT/Claude のチャット画面が見えるとストーリー性◎

**③プレビュー表示**
- 「プレビュー」ボタンを押した後の状態
- 文字数カウントと、変換後の見た目（h2/h3、リスト、引用が綺麗に表示されている）が見える

**④Before / After（note 貼り付け結果）**
- 左：プレーンテキストで貼った場合の note エディタ（装飾なし）
- 右：本拡張機能でコピーして貼った note エディタ（装飾あり）
- 真ん中に矢印 + 「Markdown for note でこの差！」のキャプション

**⑤「他のツール」セクション**
- ポップアップを下までスクロールした状態
- note Word Counter+ と note Booster のカードが見える
- 「他にも便利なツールを開発中」のキャプション

### 撮影手順
1. Chrome の拡張機能ページ（`chrome://extensions/`）でデベロッパーモード ON
2. ZIP 化前のフォルダを「パッケージ化されていない拡張機能を読み込む」で読み込む
3. 1280×800 の解像度に Chrome ウィンドウをリサイズ（DevTools のレスポンシブモードか、外部ツール `Window Resizer` 等を使用）
4. ポップアップを開き、各シナリオの状態を作って `Win + Shift + S`（Windows）でスクリーンショット
5. Canva / Figma で背景・キャプション・矢印を追加
6. PNG で書き出し → `store-listing/screenshots/` に `01-hero.png` ～ `05-other-tools.png` として保存

## 3. プロモーション画像（任意だが推奨）

| 種類 | サイズ | 必要度 |
|---|---|---|
| 小プロモーションタイル | 440×280 px | 任意（おすすめ枠掲載時に使用される） |
| マーキー | 1400×560 px | 任意 |

ストアの「おすすめ」枠に乗りたい場合は小プロモーションタイルを用意。デザインはアイコンと同系統（緑背景＋白ロゴ＋短いキャッチコピー「ワンクリックでnoteへ」）で OK。
