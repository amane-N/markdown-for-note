# Markdown for note プライバシーポリシー

最終更新日：2026年5月3日

「Markdown for note」（以下「本拡張機能」）は、ユーザーのプライバシーを最大限尊重します。本拡張機能におけるデータの取り扱いについて、以下のとおり明示します。

## 1. 個人情報の収集について

本拡張機能は、ユーザーの個人情報（氏名、メールアドレス、IPアドレス、閲覧履歴等）を一切収集しません。

## 2. 通信について

本拡張機能は、外部サーバーとの通信を一切行いません。すべての処理は、お使いのブラウザ内で完結します。これは Manifest V3 の `host_permissions` を一切宣言していないこと、および本拡張機能のソースコード（オープンソース／パッケージ内すべて閲覧可能）から確認できます。

## 3. ユーザーの入力テキストについて

ユーザーが入力した Markdown テキストおよび変換結果（HTML）は、お使いのブラウザのクリップボードにコピーされるのみです。本拡張機能の開発者または第三者がアクセスできる形で保存・送信されることはありません。

## 4. 設定情報の保存について

本拡張機能の設定（h1→h2変換のON/OFF、画像注釈のON/OFF、自動プレビューのON/OFF等）は、Chrome の `chrome.storage.local` API を用いてユーザーのローカルブラウザ内にのみ保存されます。これらの情報が外部に送信されることはありません。

## 5. 第三者サービスについて

本拡張機能は、Google Analytics、広告ネットワーク、トラッキングツール、その他の第三者サービスを一切使用していません。

## 6. Cookieについて

本拡張機能は Cookie を使用しません。

## 7. ユーザー権利

ユーザーはいつでも、Chrome の拡張機能管理画面から本拡張機能を削除することで、ローカルに保存された設定情報を完全に消去することができます（Chrome の `chrome://extensions/` → 本拡張機能 → 「削除」）。

## 8. 本ポリシーの変更について

本ポリシーは、必要に応じて変更されることがあります。重大な変更があった場合は、本ページ上部の「最終更新日」を更新し、Chrome Web Store の更新履歴で告知します。
